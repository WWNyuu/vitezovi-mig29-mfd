# MiG-29 WW MFD

A modern multifunction display for the DCS MiG-29A Fulcrum, by the 127th Vitezovi FAS "Wild Wolves". It adds a datalink SA page, PICTURE and intercept steering, NAV with time on target, fuel planning, stores, RWR and a full power-up sequence to the retrofit MFD in KRN MODS' cockpit modernization.

**Website and pilot manual:** see the GitHub Pages site of this repository (`index.html`, `manual.html`).

## Requirements

- DCS: MiG-29A Fulcrum (full-fidelity module)
- KRN MODS' "MiG-29A(M) Cockpit Modernization" V1.0.3, from KRN's own release: https://files.digitalcombatsimulator.com/en/files/3350140/

This is an add-on to KRN's mod, published with KRN's agreement. The download contains none of KRN's files; the installer patches your own copy of KRN's mod and keeps the originals, and the uninstaller puts them back.

## Install

1. Install KRN's mod into `Saved Games\DCS\Mods\tech`.
2. Download `downloads/Vitezovi_MiG-29_MFD_Addon_v1.7.5.zip`, unzip it anywhere and double-click `INSTALL.bat` (close DCS first).
3. In the jet: battery on, press PWR (top-left rocker on the MFD), choose a cartridge.
